# Contributing

Thanks for helping! This project is small on purpose: plain Node.js, no dependencies, two hooks.

- **Bug?** Open an issue with your Claude Code version, OS and what happened. Please don't paste notebook or transcript content: it may contain your private work.
- **Idea?** Open an issue first so we can agree on the shape before you write code.
- **Pull requests:** keep them focused, no new dependencies, run `npm test` before pushing.
- **New secret pattern?** Add it to `SECRET_PATTERNS` in `src/notebook.mjs` with a test using an obviously fake value.
